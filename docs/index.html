关于

只读、自用、不打扰。

这个工具不代查、不代填，也不修改任何校内数据。登录在学校系统里完成，应用只做只读抓取；没有中转服务器，也不保存账号密码。

与城固一中及任何学校系统没有隶属或合作关系。

为什么还要自己粘贴链接？

登录在校内系统完成，应用不接触账号密码，只对你给出的成绩分析页面做只读解析。

数据会被上传吗？

不会。成绩只在本机内存里解析和展示，应用没有后端，也不做统计上报。

为什么有四个下载地址？

GitHub 是主渠道；另外三条是给国内网络和备用场景留的，内容完全一致，签名相同。
